# 滤波器选择指南

## 一、滤波器类型选择（Butterworth vs Chebyshev）

### Butterworth（巴特沃斯）滤波器

**特点：**
- ✅ 通带响应**完全平坦**（无纹波）
- ✅ 相位响应线性好
- ⚠️ 过渡带相对较宽（较缓）
- ✅ 计算量小，适合实时处理

**适用场景：**
- **ADC数据平滑**（最常用）
- 需要保持信号幅值准确的应用
- 对相位有要求的应用（如音频处理）
- 嵌入式系统（资源受限）

**不适用场景：**
- 需要非常陡峭的过渡带
- 对通带纹波不敏感但需要快速衰减

---

### Chebyshev（切比雪夫）滤波器

**特点：**
- ✅ 过渡带**非常陡峭**（相同阶数下）
- ⚠️ 通带或阻带有**纹波**（可控制）
- ⚠️ 相位响应不如Butterworth
- ⚠️ 计算量稍大

**适用场景：**
- 需要**快速衰减**不需要的频率
- 通带纹波可接受的场景
- 需要**窄带滤波**（如带通、带阻）
- 对过渡带陡峭度要求高的应用

**不适用场景：**
- ADC数据平滑（Butterworth更合适）
- 需要精确保持信号幅值的应用
- 对相位敏感的应用

---

## 二、滤波器类型选择（低通/高通/带通/带阻）

### 1. 低通滤波器（Low Pass）- **最常用**

**作用：** 保留低频信号，滤除高频噪声

**频率响应：**
```
幅值
  |     ┌───────
  |    ╱
  |   ╱
  |  ╱
  | ╱
  |╱───────────────> 频率
  0    fc
```

**使用场景：**

| 应用场景 | 说明 | 示例 |
|---------|------|------|
| **ADC数据平滑** | 去除ADC采样中的高频噪声 | 温度、压力、光照传感器 |
| **传感器去噪** | 平滑缓慢变化的传感器数据 | 温度、湿度、气体浓度 |
| **信号平滑** | 平滑波动较大的测量值 | 电压、电流测量 |
| **抗混叠** | 在采样前去除高频成分 | 数据采集系统 |
| **直流信号提取** | 从含噪声的信号中提取直流分量 | 电池电压监测 |

**示例代码：**
```c
// 温度传感器平滑
BWLowPass* temp_filter = create_bw_low_pass_filter(2, 10, 1);
// 采样率10Hz，截止频率1Hz，2阶

// 压力传感器平滑
BWLowPass* pressure_filter = create_bw_low_pass_filter(2, 50, 10);
// 采样率50Hz，截止频率10Hz，2阶
```

---

### 2. 高通滤波器（High Pass）

**作用：** 保留高频信号，滤除低频干扰

**频率响应：**
```
幅值
  |                ────────
  |               ╱
  |              ╱
  |             ╱
  |            ╱
  |───────────╱───────────> 频率
  0          fc
```

**使用场景：**

| 应用场景 | 说明 | 示例 |
|---------|------|------|
| **去除直流偏移** | 去除信号中的直流分量 | 交流信号处理 |
| **去除低频干扰** | 滤除工频干扰（50/60Hz） | 传感器信号处理 |
| **提取变化信号** | 只保留快速变化的部分 | 振动检测、冲击检测 |
| **边缘检测** | 检测信号的变化 | 运动检测、状态变化 |

**示例代码：**
```c
// 去除直流偏移
BWHighPass* ac_filter = create_bw_high_pass_filter(2, 1000, 10);
// 采样率1kHz，截止频率10Hz，去除10Hz以下的直流和低频

// 振动检测（只保留高频振动）
BWHighPass* vibration_filter = create_bw_high_pass_filter(4, 1000, 50);
// 采样率1kHz，截止频率50Hz，只保留50Hz以上的振动
```

---

### 3. 带通滤波器（Band Pass）

**作用：** 只保留特定频率范围的信号

**频率响应：**
```
幅值
  |     ┌─────┐
  |    ╱       ╲
  |   ╱         ╲
  |  ╱           ╲
  | ╱             ╲
  |╱───────────────╲─────> 频率
  0  fl    fc    fu
```

**使用场景：**

| 应用场景 | 说明 | 示例 |
|---------|------|------|
| **特定频率提取** | 提取特定频率的信号 | 心率检测（1-2Hz） |
| **信号解调** | 从载波中提取调制信号 | 通信系统 |
| **频带选择** | 只处理特定频段的信号 | 音频处理、语音识别 |
| **干扰抑制** | 去除特定频率范围外的干扰 | 传感器信号处理 |

**示例代码：**
```c
// 心率检测（提取1-2Hz的心率信号）
BWBandPass* heart_rate_filter = create_bw_band_pass_filter(4, 100, 1.0, 2.0);
// 采样率100Hz，通带1-2Hz，4阶

// 语音信号处理（300-3400Hz）
BWBandPass* voice_filter = create_bw_band_pass_filter(4, 8000, 300, 3400);
// 采样率8kHz，通带300-3400Hz
```

---

### 4. 带阻滤波器（Band Stop / 陷波器）

**作用：** 滤除特定频率范围的信号，保留其他频率

**频率响应：**
```
幅值
  |─────────┐     ┌─────────
  |         │     │
  |         │     │
  |         │     │
  |         │     │
  |─────────┴─────┴─────────> 频率
  0  fl    fc    fu
```

**使用场景：**

| 应用场景 | 说明 | 示例 |
|---------|------|------|
| **工频干扰去除** | 去除50Hz或60Hz工频干扰 | 传感器信号处理 |
| **特定频率抑制** | 去除已知的干扰频率 | 电源噪声、电机干扰 |
| **陷波滤波** | 去除特定频率的干扰 | 音频处理、信号清理 |
| **谐波抑制** | 去除特定频率的谐波 | 电力系统、电机控制 |

**示例代码：**
```c
// 去除50Hz工频干扰
BWBandStop* notch_50hz = create_bw_band_stop_filter(4, 1000, 48, 52);
// 采样率1kHz，阻带48-52Hz，4阶

// 去除60Hz工频干扰
BWBandStop* notch_60hz = create_bw_band_stop_filter(4, 1000, 58, 62);
// 采样率1kHz，阻带58-62Hz
```

## 三、选择决策树

```
开始
  │
  ├─ 需要去除高频噪声？
  │   └─ 是 → 使用【低通滤波器】
  │       └─ 推荐：Butterworth低通（ADC平滑最常用）
  │
  ├─ 需要去除低频干扰或直流？
  │   └─ 是 → 使用【高通滤波器】
  │
  ├─ 需要提取特定频率范围？
  │   └─ 是 → 使用【带通滤波器】
  │       └─ 需要陡峭过渡？→ Chebyshev带通
  │
  └─ 需要去除特定频率（如50Hz工频）？
      └─ 是 → 使用【带阻滤波器】
          └─ 推荐：Butterworth带阻（陷波器）
```

## 四、实际应用案例

### 案例1：温度传感器数据平滑

**需求：** 温度变化缓慢，需要平滑ADC采样值

**选择：**
- ✅ **Butterworth低通滤波器**
- 采样率：10Hz（每100ms采样一次）
- 截止频率：1Hz（保留缓慢变化，滤除快速波动）
- 阶数：2阶

**代码：**
```c
BWLowPass* temp_filter = create_bw_low_pass_filter(2, 10, 1);
float filtered_temp = bw_low_pass(temp_filter, adc_value);
```

---

### 案例2：去除50Hz工频干扰

**需求：** 传感器信号受到50Hz电源干扰

**选择：**
- ✅ **Butterworth带阻滤波器**
- 采样率：1000Hz
- 阻带：48-52Hz（去除50Hz及其附近频率）
- 阶数：4阶（需要较好的抑制效果）

**代码：**
```c
BWBandStop* notch_filter = create_bw_band_stop_filter(4, 1000, 48, 52);
float clean_signal = bw_band_stop(notch_filter, sensor_value);
```

---

### 案例3：心率检测

**需求：** 从PPG信号中提取心率（1-2Hz）

**选择：**
- ✅ **Butterworth带通滤波器**
- 采样率：100Hz
- 通带：1-2Hz（心率范围）
- 阶数：4阶（需要较好的频率选择性）

**代码：**
```c
BWBandPass* heart_filter = create_bw_band_pass_filter(4, 100, 1.0, 2.0);
float heart_signal = bw_band_pass(heart_filter, ppg_value);
```

---

### 案例4：振动检测

**需求：** 只检测高频振动，忽略缓慢变化

**选择：**
- ✅ **Butterworth高通滤波器**
- 采样率：1000Hz
- 截止频率：50Hz（只保留50Hz以上的振动）
- 阶数：2阶

**代码：**
```c
BWHighPass* vibration_filter = create_bw_high_pass_filter(2, 1000, 50);
float vibration = bw_high_pass(vibration_filter, accelerometer_value);
```

---

### 案例5：需要陡峭过渡带的窄带滤波

**需求：** 需要非常陡峭的过渡带，通带纹波可接受

**选择：**
- ✅ **Chebyshev带通滤波器**
- 采样率：8000Hz
- 通带：300-3400Hz（语音频段）
- 阶数：4阶
- Epsilon：0.1（控制纹波大小）

**代码：**
```c
CHEBandPass* voice_filter = create_che_band_pass_filter(4, 0.1, 8000, 300, 3400);
float voice_signal = che_band_pass(voice_filter, audio_sample);
```

## 六、参数选择建议

### 采样频率（Sampling Frequency）
- 根据实际采样间隔计算：`采样频率 = 1000 / 采样间隔(ms)`
- 必须满足：`采样频率 ≥ 2 × 最高信号频率`（奈奎斯特定理）

### 截止频率（Cutoff Frequency）
- **低通滤波器：** 采样频率的 1/5 到 1/10
- **高通滤波器：** 根据要保留的最低频率设置
- **带通/带阻：** 根据实际需求设置上下限

### 滤波器阶数（Order）
- **2阶：** 推荐用于大多数应用（计算量小，效果足够）
- **4阶：** 需要更好滤波效果时使用（计算量较大）

### Epsilon（仅Chebyshev）
- **0.1-0.5：** 较小的纹波（推荐）
- **0.5-1.0：** 较大的纹波，但过渡带更陡

---

## 七、总结

**对于ADC数据平滑（你的主要需求）：**

1. ✅ **首选：Butterworth低通滤波器**
2. ✅ **参数：** 采样率根据实际采样间隔，截止频率为采样率的1/5到1/10
3. ✅ **阶数：** 2阶（推荐）或4阶
4. ✅ **不推荐：** Chebyshev（通带纹波会影响ADC值的准确性）

**其他场景：**
- 需要陡峭过渡带 → Chebyshev
- 需要去除特定频率 → 带阻滤波器
- 需要提取特定频段 → 带通滤波器
- 需要去除直流/低频 → 高通滤波器
